\# DevOps CI/CD Pipeline Project



End-to-end CI/CD pipeline using \*\*Jenkins, Docker, Kubernetes, and AWS (Terraform)\*\*.



\## Features



\- CI/CD automation: build → test → deploy

\- Dockerized app deployment

\- Kubernetes manifests for container orchestration

\- Infrastructure managed with Terraform on AWS
