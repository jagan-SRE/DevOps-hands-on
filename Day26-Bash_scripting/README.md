# Day 26 – Bash Scripting

This folder contains **hands-on Bash scripts** for Day 26 of DevOps practice.  
The goal is to learn **loops, if/else statements, and automation scripts** in Linux using Bash.

---

## 📁 Folder Contents

| File | Description |
|------|-------------|
| `loops.sh` | Demonstrates a basic `for` loop in Bash. Prints numbers 1–5. |
| `if_else.sh` | Demonstrates `if/else` statements. Checks if a file exists (`/etc/passwd`). |
| `automation.sh` | A small automation script to monitor disk usage and alert if usage exceeds 80%. |

---
